# AccessMap AI

Agentic RAG-based accessibility assessment and inclusive place recommendation system.

## Status

Day 1 of the mid-semester sprint (target: Sept 24 review). Currently: bare FastAPI
server, nothing else wired up yet. See `docs` in the linked Claude Project for the
full implementation plan and architecture.

## Running the backend locally

```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then open http://127.0.0.1:8000 in a browser — you should see
`{"status": "ok", "message": "AccessMap AI backend is running"}`.

Interactive API docs (auto-generated by FastAPI, this becomes our demo UI
before we build a frontend): http://127.0.0.1:8000/docs
